## Цель

Сделать играбельную мобильную игру "Уличный повар" — ты держишь палатку
с марокканской едой, обслуживаешь очередь клиентов, зарабатываешь, качаешь
палатку, открываешь новые локации.

Деплой через GitHub Pages на URL
`https://flikflo.github.io/frontier-the-game/tajine-tamagotchi/`

Тестовое устройство — **Pixel 8a**. Надо чтобы работало как на телефоне,
так и на десктопе в рамке "телефона".

## Техническое решение

**Canvas для игровой сцены + HTML/CSS для меню/попапов.**

Почему:
- DOM-анимации для персонажей и сцены = тонна CSS, перебор
- Canvas 2D даёт 60fps, компактный код, легко анимировать
- HTML/CSS только для статичных экранов (меню, апгрейды, гардероб)

Без фреймворков. Чистый JS + Canvas API. Файлы:
- `index.html` (~50 строк)
- `style.css` (~200 строк) — только UI
- `game.js` (~800-1200 строк) — вся игра

## План разработки (фазами, коммить каждую фазу)

### Фаза 1: Скелет + сцена палатки (канва-версия MVP)
- Canvas фулскрин, ресайз под экран
- Scene manager (состояния: menu / create / hub / game / dayEnd / upgrades)
- Draw функция палатки сбоку: стены, прилавок, крыша, вывеска, огонь, тажин
- Простой рендер повара-стикмена (без кастомизации пока)
- Фон: небо градиентом, земля, марокканский паттерн

Критерий готовности: открыл — видишь нарисованную палатку сбоку.

### Фаза 2: Создание персонажа
- Экран с picker'ами: лицо (4 варианта), борода (4), фартук (4 цвета), имя, трейт
- Превью персонажа слева обновляется при выборе
- Сохранение в localStorage под ключом `streetchef_v1`
- При повторном заходе — сразу в хаб

Критерий: создал повара, перезагрузил — он сохранён.

### Фаза 3: Хаб + запуск дня
- Экран хаба: превью палатки + персонажа, кнопки "В палатку / Апгрейды /
  Гардероб / Рецепты"
- Статы сверху: 🪙 монеты, 💎 алмазы, ⭐ репутация
- Кнопка "В палатку" стартует день

Критерий: можно зайти в хаб, вернуться, день запускается.

### Фаза 4: Геймплей дня (ядро!)
- Таймер дня: 60 секунд
- Клиенты спаунятся каждые 5-10с, идут к палатке с анимацией
- Очередь макс 3 клиента (апгрейдится)
- Над каждым клиентом thought-bubble с заказом (🍲/🥣/🍵)
- У клиента таймер терпения (круг-прогресс над головой)
- Тап клиента → появляется cook overlay

### Фаза 5: Мини-игра готовки (3 секунды)
- Показываются 3 ингредиента в виде иконок
- Игрок тапает их по порядку
- Полоска прожарки движется туда-обратно, тап-остановка в зелёной зоне
- Кнопка "Подать" → анимация блюда летит клиенту, монеты разлетаются

### Фаза 6: Конец дня
- Экран итогов: обслужено / пропущено / заработано / +реп / чаевые / итого
- Анимация счёта денег
- Кнопка "В хаб"

### Фаза 7: Дерево апгрейдов
- 3 ветки: Кухня / Сервис / Маркетинг (см. `streetchef.md`)
- По 3 апгрейда в каждой, покупаются по порядку
- Покупка сразу применяется (увеличивает очередь, ускоряет готовку и т.д.)

### Фаза 8: Гардероб
- Смена фартука/бороды/шапки с превью
- Коллекция открывается через "сундуки репутации" (кап 10, 20, 30 реп)

### Фаза 9: Полировка
- Звуки (опционально, через Web Audio API)
- Частицы монет более сочные
- Тряска экрана при комбо
- Day/night визуал

### Фаза 10 (будущее): Вторая локация
- После rep 10 открывается Фес
- Выбор локации на карте Марокко
- Свой набор клиентов, цен, рецептов

## Важные технические заметки

### Viewport
```html
<meta name="viewport" content="width=device-width,initial-scale=1,user-scalable=no,viewport-fit=cover">
```

### Canvas setup
```js
const cv = document.getElementById('game');
const ctx = cv.getContext('2d');
const DPR = window.devicePixelRatio || 1;
function resize() {
  cv.width = window.innerWidth * DPR;
  cv.height = window.innerHeight * DPR;
  cv.style.width = window.innerWidth + 'px';
  cv.style.height = window.innerHeight + 'px';
  ctx.setTransform(DPR,0,0,DPR,0,0);
}
window.addEventListener('resize', resize);
resize();
```

### Safe area
Не забывай `env(safe-area-inset-top)` для HUD и `inset-bottom` для кнопок.
На Pixel 8a нижние кнопки обрезались системным жестом — именно из-за этого.

### Game loop
```js
let last = performance.now();
function loop(t) {
  const dt = Math.min(50, t - last) / 1000;
  last = t;
  update(dt);
  render();
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);
```

### Scene manager
```js
const state = { scene: 'menu', /* ... */ };
const scenes = {
  menu: { enter, update, render, click, exit },
  create: { ... },
  hub: { ... },
  game: { ... },
  // ...
};
function setScene(name) {
  scenes[state.scene]?.exit?.();
  state.scene = name;
  scenes[name].enter?.();
}
```

### Click handling
Работай через `pointerdown/pointerup` (а не click) — лучше отклик на
мобилках. Координаты учитывай с DPR.

### Save
Один объект в `localStorage['streetchef_v1']`. Сохраняй после каждого
значимого действия (конец дня, покупка апгрейда, смена шмотки).

## Чего избегать

- Огромных файлов (>1000 строк) — дробить логически
- Сложного CSS для игровой сцены — всё через canvas
- Фреймворков (Vue, React) — оверкилл для такой игры
- Блокирующих setInterval — всё через requestAnimationFrame
- Забывать про мобилку (ширина экрана, safe-area, тач-ивенты)

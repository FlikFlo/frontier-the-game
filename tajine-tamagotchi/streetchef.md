# Уличный повар — Дизайн

## Концепт
Ты держишь уличную палатку с марокканской едой. Сбоку видно палатку,
тебя-повара, клиентов в очереди. Готовишь быстро, обслуживаешь, растишь
империю по всему Марокко.

## MVP
- 1 локация: Марракеш (Джемаа-эль-Фна)
- 3 блюда: тажин с курицей, кускус, мятный чай
- 3 типа клиентов: турист, бабушка, студент
- 1 день = 60 секунд игрового времени
- Кастомизация повара (лицо, борода, цвет фартука, имя, трейт)
- RPG-дерево прокачки палатки (3 ветки x 3 апгрейда)

## Экраны
1. **Менеджер сохранений** (новый/продолжить)
2. **Создание персонажа** — лицо / борода / фартук / имя / трейт
3. **Главный хаб** — статы, кнопка "В палатку", "Апгрейды", "Гардероб"
4. **Палатка (день)** — основной геймплей
5. **Конец дня** — итоги, монеты, репутация
6. **Дерево прокачки** — 3 ветки (Кухня / Сервис / Маркетинг)
7. **Гардероб** — смена фартуков/шапок

## Игровой день
- 60 сек (апгрейдится до 90)
- Клиенты приходят по таймеру (каждые 5-10с)
- Макс. 3 в очереди одновременно (апгрейд увеличивает)
- У каждого таймер терпения (10-20с)
- Клиент показывает заказ эмодзи
- Тапаешь клиента → видишь его заказ → готовишь (3-секундная мини-игра)
- Подал → монеты + репутация, новый клиент на его место
- Если ушёл сам — штраф к репутации

## Мини-готовка
Когда клиент выбран:
1. Показывается 3 ингредиента нужных для блюда
2. Тапаешь их по очереди (правильный порядок = бонус)
3. Полоска готовности заполняется, отпусти в зелёной зоне
4. Сервируешь

Время на всё: 3 секунды. Быстро, тактильно.

## Клиенты
- **Турист** (60%) — терпит 15с, платит 50🪙, +1 rep
- **Бабушка** (25%) — терпит 20с, платит 30🪙, +3 rep
- **Студент** (15%) — терпит 10с, платит 20🪙, +0 rep

Появляются "VIP" (5%) после rep 20: критик, богач, шейх.

## Персонаж
- **Лицо**: 4 варианта
- **Борода**: нет / усы / короткая / длинная
- **Фартук**: базовый → разблокируемые цвета
- **Имя**: ввод текстом
- **Трейт** (выбирается при создании):
  - Скоростной: готовка на 15% быстрее
  - Щедрый: +20% чаевых
  - Харизматик: клиенты терпят +30%

## Дерево прокачки палатки

### Кухня 🔥
- Лучшая печь (-10% время готовки) — 100🪙
- Два тажина одновременно — 300🪙
- Мастерская специй (шанс х2 чаевых) — 800🪙

### Сервис 👥
- Больше стульев (очередь 4 вместо 3) — 150🪙
- Музыка (+5с терпения клиентам) — 400🪙
- Помощник (автоготовка раз в 10с) — 1000🪙

### Маркетинг 📢
- Вывеска (+20% клиентов) — 120🪙
- Листовки (+10% цена блюд) — 500🪙
- Слава (шанс VIP клиентов х2) — 1200🪙

## Репутация
- Растёт от хорошо обслуженных клиентов
- Падает если клиент ушёл
- Rep = уровень локации, открывает новые рецепты/клиентов
- Rep 10 → откроется 2-й город (Фес)

## Экономика
- Базовый доход за день: 200-500🪙
- Апгрейды дорожают по кривой
- Фартуки/косметика — отдельная валюта (алмазы) из "сундуков репутации"

## Прогрессия (после MVP)
- Новые города (Фес, Шефшауэн, Эс-Сувейра, Сахара, Касабланка)
- Путешествие между ними (выбор локации на карте)
- Ивенты (фестиваль, свадьба, рамадан)
- Рецепты — коллекция на 30+ блюд
- Боссы-критики (забег на 3 минуты за звёзды)

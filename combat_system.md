# Frontier — Система Автобоя

---

## 1. КОНЦЕПЦИЯ

Герой сражается **автоматически**. Игрок не управляет действиями в бою напрямую. Вся стратегия — в **подготовке**: билд, экипировка, Зиры, выбор компаньона, расходники.

Бой — это **проверка подготовки**. Если игрок правильно собрал билд под конкретных врагов, герой победит. Если нет — проиграет, и нужно переоснаститься.

**Ключевой вопрос дизайна:** Бой должен быть интересно **смотреть**, даже если игрок не управляет. Анимации, критические моменты, активации Зиров — все это создает зрелище.

---

## 2. СТРУКТУРА БОЯ

### Инициация
- Герой встречает группу врагов на вылазке
- Экран переходит в боевой режим (как в Darkest Dungeon — вид сбоку, 2D)
- Герой слева, враги справа. Компаньон рядом с героем.

### Раунды
Бой идет **по раундам** с полосой инициативы (timeline):
1. Все участники (герой, компаньон, враги) имеют **Скорость**
2. Скорость определяет, как часто персонаж действует
3. Полоса инициативы показывает порядок ходов (игрок видит кто ходит следующим)

### Действия героя (автоматические)
Каждый ход герой выполняет одно действие по приоритету:

```
1. Если HP < 20% и есть зелье лечения → Использовать зелье
2. Если есть активный Зир и цель подходит → Активировать Зир
3. Если Зир на перезарядке → Обычная атака оружием
4. Если несколько целей → Атаковать цель с наименьшим HP (добивание)
```

### Настраиваемое поведение (Тактики)
Игрок может настроить **Тактику** до боя — простые правила AI:

| Тактика | Поведение |
|---------|----------|
| **Агрессивная** | Приоритет урона. Зиры используются при первой возможности. Зелья только при HP < 10% |
| **Осторожная** | Приоритет выживания. Зелья при HP < 40%. Зиры экономятся для сильных врагов |
| **Сбалансированная** | По умолчанию. Зелья при HP < 20%. Зиры по мере готовности |
| **Фокус на боссе** | Игнорирует мелких врагов, весь урон в самого сильного |
| **Защитная** | Максимум блоков/уклонений, контратаки вместо прямых атак |

### Конец боя
- **Победа:** Все враги убиты → лут, опыт
- **Поражение:** HP героя = 0 → вылазка прервана, герой возвращается в крепость раненым (теряет часть добычи)
- **Бегство:** Игрок может нажать «Отступить» в любой момент (занимает 1-2 раунда, враги продолжают бить)

## 3. БОЕВЫЕ МЕХАНИКИ

### Физический урон
```
Урон = (Физ.Атака героя - Броня врага) * модификатор оружия * рандом(0.9-1.1)
```
- Оружие ближнего боя: высокий базовый урон
- Оружие дальнего боя: первый удар раньше, но урон ниже

### Магический урон (через Зиры)
```
Урон = (Маг.Атака + Мощность Зира) * бонус кристалла * эффективность школы
```
- Зиры имеют ограниченное число использований за бой
- После использования — перезарядка (несколько раундов)
- Зир изнашивается и в итоге разрушается → нужен новый

### Таблица эффективности школ

| Школа атаки | Силен против | Слаб против |
|-------------|-------------|-------------|
| **Огонь** | Земля, Лед (подтип Воды) | Вода |
| **Вода** | Огонь | Земля, Воздух |
| **Земля** | Воздух, Вода | Огонь |
| **Воздух** | Земля | Огонь |
| **Свет** | Тьма, Нежить | — |
| **Тьма** | Свет, Живые | — |
| **Кровь** | Все (но стоит HP) | — |

### Критические удары
- Базовый шанс крита: 5%
- Увеличивается от Рефлекса, навыков, экипировки
- Крит = x1.5 урон (до x2.5 с навыками)
- Визуально: замедление кадра, вспышка, текст крита

### Статусные эффекты

| Эффект | Источник | Действие |
|--------|---------|----------|
| **Горение** | Огонь | Урон каждый раунд, 3 раунда |
| **Заморозка** | Вода | Пропуск хода (шанс) |
| **Оглушение** | Земля | Пропуск следующего хода (100%) |
| **Ускорение** | Воздух | +50% скорости на 3 раунда |
| **Благословение** | Свет | Регенерация HP каждый раунд |
| **Проклятие** | Тьма | -30% урон и защита |
| **Кровотечение** | Кровь | Урон каждый раунд, лечит атакующего |
| **Отравление** | Алхимия | Нарастающий урон каждый раунд |

## 4. ТИПЫ ВРАГОВ

### По поведению

| Тип | Описание | Контр-стратегия |
|-----|----------|----------------|
| **Рядовой** | Средние статы, стандартные атаки | Любой билд |
| **Танк** | Высокий HP и броня, низкий урон | Магия, обход брони |
| **Снайпер** | Низкий HP, высокий урон, бьет с тыла | Агрессивная тактика (убить первым) |
| **Маг** | Магические атаки, бафы союзников | Высокое сопротивление, быстрое убийство |
| **Целитель** | Лечит других врагов | Фокус на целителе |
| **Берсерк** | Урон растет при потере HP | Контроль (оглушение, заморозка) |
| **Призыватель** | Вызывает дополнительных врагов | Убить до призыва |

### По среде обитания
- **Пустошь:** Мутанты, дикие звери, бандиты
- **Шахта:** Каменные големы, подземные твари, рудные элементали
- **Портальные миры:** Уникальные для каждого мира (подробнее в portal_worlds.md)

## 5. БОССЫ

### Структура боя с боссом
Боссы — многофазные бои. У босса несколько полос HP:

**Фаза 1 (100%-60% HP):** Стандартные атаки, изучаем паттерн
**Фаза 2 (60%-30% HP):** Новые способности, усиленные атаки
**Фаза 3 (30%-0% HP):** Режим ярости, максимальная опасность

### Подготовка к боссам
- Перед боем с боссом игрок видит **досье** (если разведал): тип урона, слабости, способности
- Можно вернуться в крепость и подготовить билд именно под этого босса
- Это ключевой элемент: автобой с боссом — проверка того, насколько хорошо ты подготовился

### Награда за босса
- Гарантированный эпический/легендарный предмет
- Уникальный ресурс этой локации
- Продвижение сюжета
- Разблокировка нового контента

## 6. РОЛЬ КОМПАНЬОНА В БОЮ

### Типы компаньонов

| Роль | Поведение в бою | Пример |
|------|----------------|--------|
| **Танк** | Принимает удары на себя, провоцирует врагов | Старый рейнджер-ветеран |
| **Дамагер** | Наносит дополнительный урон | Молодой наемник |
| **Поддержка** | Лечит, бафает, снимает дебафы | Бродячий алхимик |
| **Контроль** | Оглушает, замедляет, ослабляет | Маг-отшельник |

### Механики компаньона
- Компаньон действует автоматически, как и герой
- У компаньона свои HP, статы, экипировка (упрощенная: оружие + броня)
- Компаньон может «упасть» в бою — не погибает, но не может сражаться до лечения в Лазарете
- Компаньон получает часть опыта и растет в уровнях
- У каждого компаньона уникальная **ультимативная способность** (срабатывает раз за бой при определенном условии)

## 7. РАСХОДНИКИ В БОЮ

Игрок берет с собой на вылазку ограниченное число расходников:

| Расходник | Эффект | Триггер использования |
|-----------|--------|----------------------|
| **Зелье здоровья** | Восстанавливает HP | HP ниже порога (зависит от тактики) |
| **Зелье энергии** | Восстанавливает EP | EP ниже порога |
| **Противоядие** | Снимает отравление/кровотечение | При получении статуса |
| **Боевой эликсир** | Временно увеличивает урон | Автоматически в начале боя с боссом |
| **Дымовая бомба** | Гарантированное бегство | Только при ручном нажатии «Отступить» |

### Лимит слотов
- **Начало игры:** 3 слота под расходники
- **С прокачкой:** до 6 слотов (через пояс, навыки, крепость)

## 8. СКОРОСТЬ БОЯ И ВИЗУАЛ

### Скорость
- Базовая скорость: бой длится 30-60 секунд (обычная группа врагов)
- Кнопки ускорения: **x1**, **x2**, **x3**
- Бои с боссами: 2-5 минут на базовой скорости

### Визуальные элементы
- **Полоса инициативы** вверху экрана — порядок ходов
- **HP/EP бары** над каждым участником
- **Анимации:** удары, магия, критические попадания с эффектами
- **Числа урона** выскакивают над головами
- **Активация Зира:** особый эффект — бумага разворачивается, светится, символ пульсирует
- **Ульта компаньона:** замедление, крупный план, мощный эффект

### Пауза
Игрок может поставить бой на паузу в любой момент, чтобы:
- Оценить ситуацию
- Нажать «Отступить»
- Использовать расходник вручную (единственное ручное вмешательство)

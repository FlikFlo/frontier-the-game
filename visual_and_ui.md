# Frontier — Визуальный стиль и UI

---

## 1. АРТ-СТИЛЬ

### Направление
**Рисованное 2D** с детализированными фонами и анимированными спрайтами. Ближе к Darkest Dungeon по уровню детализации, но с более насыщенной цветовой палитрой (не только мрак).

### Палитра
- **Крепость:** Теплые тона — охра, камень, мягкий свет костров, зеленые кристаллы
- **Пустошь:** Блеклые, выгоревшие тона — серый, бежевый, ржавый
- **Портальные миры:** У каждого своя доминирующая палитра (зеленый, синий, красный и т.д.)
- **Бой:** Контрастные вспышки на темном фоне

### Стиль персонажей
- Спрайты сбоку (как в Darkest Dungeon)
- Четкие силуэты — каждый компаньон и тип врага различим с первого взгляда
- Анимация: idle, атака, получение урона, использование Зира, смерть
- Герой: экипировка визуально отображается на спрайте

### Стиль окружения
- Фоны рисованные, многослойные (параллакс)
- Атмосферные эффекты: туман, свечение кристаллов, искры, пыль
- Каждая локация визуально уникальна

## 2. ОСНОВНЫЕ ЭКРАНЫ

### Экран 1: КРЕПОСТЬ (Хаб)
**Вид:** Изометрический / вид сбоку в разрезе (как Fallout Shelter, но красивее)

```
┌─────────────────────────────────────────┐
│  [Башня]  [Стены]        [Башня]       │
│  ┌──────┬──────┬──────┬──────┐          │
│  │Казар.│Кузни.│Торг. │Стрел.│  Этаж 1 │
│  ├──────┼──────┼──────┼──────┤          │
│  │Лазар.│Алхим.│Конюш.│Библ. │  Этаж 2 │
│  ├──────┼──────┼──────┼──────┤          │
│  │Крист.│Порт. │ ???  │ ???  │  Этаж 3 │
│  ├──────┼──────┼──────┼──────┤          │
│  │Тайн. │Хран. │Зерк. │ ???  │ Подзем. │
│  └──────┴──────┴──────┴──────┘          │
│                                         │
│  [Двор: Герой, NPC ходят]              │
│                                         │
│  [Меню]  [Карта]  [Инвентарь]  [Портал]│
└─────────────────────────────────────────┘
```

- Помещения кликабельны → переход в интерфейс помещения
- NPC видны в своих помещениях (кузнец у наковальни, алхимик у котла)
- Не проявленные комнаты — затемненные контуры
- Проявляющиеся комнаты — светящийся эффект

- Локации как иконки на карте
- Зачищенные локации — яркие, активные — мигающие
- Линии маршрутов между крепостью и локациями
- Информация о расстоянии и сложности при наведении

### Экран 4: БОЙ (Автобой)
**Вид:** Сбоку, как Darkest Dungeon

```
┌─────────────────────────────────────────┐
│  [Полоса инициативы: Герой→Враг1→...]  │
│                                         │
│                                         │

│   EP ████                               │
│                                         │
│      -45 КРИТ!                          │
│                                         │
│  Тактика: Сбалансированная    [x1][x2] │

│                                         │
```

- Полоса инициативы сверху
- Числа урона анимируются
- Кнопки ускорения (x1, x2, x3)
- Кнопка паузы для ручного использования расходников

## 3. UI ЭЛЕМЕНТЫ

### Шрифты
- **Заголовки:** Декоративный средневековый шрифт (но читаемый)
- **Текст:** Чистый sans-serif для удобства чтения
- **Числа урона:** Жирный, контрастный

### Иконки
- Ресурсы: простые, понятные силуэты
- Кристаллы: цветные, с легким свечением
- Зиры: символы-руны в рамке цвета школы
- Экипировка: детализированные иконки

### Цветовая система качества
- Обычное: серая рамка
- Необычное: зеленая рамка
- Редкое: синяя рамка + легкое свечение
- Эпическое: фиолетовая рамка + пульсация
- Легендарное: оранжевая рамка + золотые частицы

### Уведомления
- Всплывающие плашки сверху экрана
- Цвет: зеленый (хорошее), красный (плохое), желтый (внимание)
- Примеры: «Набег через 2 дня!», «Кузнец создал Клинок Бури», «Комната проявлена»

## 4. ЗВУКОВОЕ ОФОРМЛЕНИЕ

### Музыка
- **Крепость:** Спокойная, атмосферная. Легкие струнные, приглушенные ударные. Ощущение дома.
- **Вылазка:** Напряженная, нарастающая. Зависит от локации (барабаны в шахте, завывание ветра в горах)
- **Бой:** Динамичная, ритмичная. Ускоряется при низком HP.
- **Босс:** Эпическая, оркестровая. Каждый босс — уникальная тема.
- **Портальные миры:** Каждый мир — уникальный саундтрек, отражающий тему.

### Звуковые эффекты
- Удары: разные для каждого типа оружия
- Магия: каждая школа имеет свой «звук» (огонь — треск, вода — журчание)
- Зиры: специфический звук разворачивания бумаги + магическая активация
- Крепость: фоновые звуки — молоток кузнеца, бульканье зелий, шаги по камню
- Портал: глубокий гул, нарастающий при активации

## 5. АНИМАЦИИ (ключевые)

### Бой
- Idle: легкое покачивание, дыхание
- Атака: замах + удар, враг вздрагивает
- Крит: замедление кадра (0.3 сек), вспышка, увеличенные числа
- Зир: бумага разворачивается вокруг оружия/рук, символ вспыхивает, эффект заклинания
- Ульта компаньона: крупный план, эпическая анимация (1-2 сек)
- Смерть врага: рассыпание / исчезновение (зависит от типа)

### Крепость
- NPC работают: кузнец бьет молотом, алхимик мешает зелье
- Проявление комнаты: стены светятся, контуры проступают, вспышка — комната готова
- Портал: кристаллы вставляются, энергия течет по линиям, портал открывается вихрем

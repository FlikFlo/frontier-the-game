# Frontier the Game - Game Design Document

## Концепция
RPG с менеджментом крепости "Фронтир" как главной базы героя.

## Основная механика

### Крепость Фронтир
- Магическая крепость на границе густого леса и пустоши
- Имеет несколько этажей, постоянно появляются новые комнаты
- Герой может управлять крепостью
- Герой остается один из группы (изначально отряд из 11 человек - старики, ветераны-инвалиды, неудачники)
- База развивается постепенно, появляются союзники
- Внутри: жилые кварталы, зал собраний, стрельбище, конюшни, мастерская оружейника

### Портал
- В крепости есть портал, активируемый комбинациями магических кристаллов
- Портал открывает двери в другие миры/пространства
- Первый мир: комбинация из 3 зеленых кристаллов
- Для новых миров нужны другие виды кристаллов
- Кристаллы добываются в разных локациях в округе

### Кристаллы и ресурсы
- Ближайший источник: заброшенная шахта в небольшой горе со снежной шапкой, недалеко от крепости
- Зеленые кристаллы - первый вид, добываются в шахте
- Шахту нужно сначала зачистить (отдельное приключение)
- Затем нанять рабочих для добычи кристаллов
- Названия кристаллов пока не придуманы

## Сюжет

### Глава 1: "Отражение в Зеркале Пределов"
- Герой останавливается в таверне для приключенцев
- Местная гильдия просит освободить крепость по соседству
- Параллельно: найти и доставить Особо ценное Зеркало
- Отряд из 11 человек отправляется на задание
- Герой основывает лагерь во внутреннем дворе крепости (данжа)
- Встреча с местными жителями, изучение Фронтира

### Глобальная цель
Пока не определена.

## Система магии

### Энергия
- Для любого использования магии требуется энергия
- Энергия = Жизнь
- Если энергия заканчивается полностью - гибель тела
- Даже простой фокус забирает энергию (манну)
- Контролю энергии учатся годами
- Некоторые пытались увеличить бассейн энергии или черпать из других источников

### Школы магии
1. Магия Воды
2. Магия Земли
3. Магия Огня
4. Магия Воздуха
5. Магия Света
6. Магия Тьмы
7. Магия Крови

### Кристаллы-усилители
- Магическую энергию можно пропускать через кристаллы определенной огранки
- Используются в жезлах, посохах, волшебных палочках
- Кристаллы позволяют обычным людям использовать магию
- Примеры: шлем с ночным зрением, колесо с защитой от огня

### Синнар (технология магической бумаги)
- **Открыватель:** Рорг Червивый - болотный эльф-маг, учитель магии земли и воды начальных уровней
- **Название:** Синнар (Син = кровь, Нар = накрывать/укрывать) - "кровавое укутывание"
- **Пользователей называли:** синнарами или червивыми
- **Суть:** бумага из необычных финиковых пальм (фиолетовые листья) + кровь + Зиры (магические символы) + кристалл = активация заклинания
- **Зиры:** магические символы, записываемые каллиграфией на специальной бумаге
- **Открытие:** случайный порез, кровь попала на бумагу с Зиром яблока, после добавления кристалла магии земли заклинание материализовало яблоко
- Пальмы найдены в мангровых зарослях болот, к северу от поселения Рорга

## Локации

### Крепость Фронтир
- На границе густого леса
- Толстые стены из массивных каменных блоков (от черного до охры)
- Квадратные башни с зубцами
- Широкий глубокий ров с зеленовато-багровой водой (питается рекой)
- За стенами - бескрайняя пустошь
- Внутренний двор с каменными плитами, клумбами, статуей героя
- Населена несколькими сотнями рейнджеров в кольчугах и кожаных доспехах

### Шахта
- В небольшой горе со снежной шапкой
- Недалеко от Башни Фронтира
- Заброшенная, со старым лагерем рудокопов (полуразрушенные дома)
- Источник зеленых кристаллов для портала

## Технологии и снаряжение
- Приборы ночного видения у разведчиков
- Магические кристаллы разных поколений (например, кристалл Огня третьего поколения)
